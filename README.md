# Agendamento da Quadra Dom Ungarelli

Projeto desenvolvido com HTML, CSS e JavaScript para abrir no Visual Studio Code.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta `quadra_dom_ungarelli` no VS Code.
3. Abra `index.html` com a extensão **Live Server** (ou abra diretamente no navegador).

## Funcionalidades
- Formulário com nome, turma, esporte, data, horário e participantes.
- Funcionamento: quarta-feira das 17h às 20h e sábado das 8h às 12h.
- Limite de 20 participantes.
- Impede solicitações duplicadas para o mesmo horário.
- Lista de solicitações, exclusão e impressão de comprovante.
- Salva dados localmente usando `localStorage`.

## Importante
Este é um projeto demonstrativo. Os registros ficam apenas no navegador e computador usados, não sincronizam entre dispositivos e não há painel real de aprovação da gestão. Para uso oficial, será necessário adicionar autenticação, banco de dados e permissões de gestor.
